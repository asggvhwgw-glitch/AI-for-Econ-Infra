# IV-PPML external validation

This directory separates local Python correctness from licensed-Stata certification.

## 1. Feature golden

Generate the deterministic feature fixture:

```bash
python validation/ivppml/generate_feature_fixture.py
```

On a licensed Stata host with current `ivppmlhdfe`, `reghdfe`, and `ftools`:

```stata
do validation/ivppml/stata/generate_golden.do validation/ivppml
```

Then compare coefficients, SEs, the full covariance matrix, N, absorbed DoF,
separation counts, mu-separation counts, and iteration counts:

```bash
PYTHONPATH=. python validation/ivppml/compare_golden.py
```

The feature matrix covers robust, two-way clustering, `standardize`, `fweight`,
`pweight`, exposure, multiple endogenous regressors/over-identification, and
`separation(all)`/mu separation.

## 2. Official Class A/B/C corpus

Place the upstream files generated by `data/DGP.do` in a directory:

- `ivppmlhdfe_ClassA.dta`
- `ivppmlhdfe_ClassB.dta`
- `ivppmlhdfe_ClassC.dta`

Generate licensed-Stata goldens:

```stata
do validation/ivppml/stata/generate_official_corpus_golden.do validation/ivppml /path/to/upstream/data
```

Then run:

```bash
PYTHONPATH=. python validation/ivppml/validate_official_corpus.py --data-dir /path/to/upstream/data
```

Class C's raw `df_a` is reported but is not a universal equality gate because
3+FE DoF conventions may differ. Coefficients, VCE, sample size, and separation
counts remain hard gates.

## Certification status

The scripts are part of the repository and are locally testable. A result is
**not** labelled Stata-certified until the CSV goldens have actually been
produced by a licensed Stata installation and both comparators exit successfully.
